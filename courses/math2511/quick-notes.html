01 先懂「钱在时间轴上移动」

阅读目标：跟上三份 lecture 的概念和公式。按页码读前 6 页，再扫第 7 页公式表、做第 8 页自检，总计约 20 分钟。长证明和重复例题已压缩。

三份 lecture 其实是一条线

Interest theory：一笔钱怎么变值；Annuity theory：一串付款怎么加总；Loan repayment：把一串未来还款的价值，匹配今天借到的钱。贯穿全课的原则是：不同时间的钱，先换到同一时点，才可以相加或比较。

A(t) 是金额；a(t) 是 1 元的成长倍数

本金 P 在时间 0 投入，A(t) 表示它在时间 t 的金额；a(t)=A(t)/P，所以 a(0)=1。若题目给的是同一个从 0 开始的基金，在 s 时投入 C，则在 t 时的价值用比值计算。

A(t) = P a(t)； C 在 s 的钱 → t 的价值 = C · a(t)/a(s)

向未来移动叫 accumulation / FV（终值）；向过去移动叫 discounting / PV（现值）。即使 t<s，同一个比值规则仍然适用。一般不能把 a(t)/a(s) 换成 a(t-s)；固定复利模型才有这个性质。

PV0 = Σk Ck/a(tk)； V(T) = Σk Ck · a(T)/a(tk)

单利与复利：利息是否继续生利息

模型增长函数（t 按年）理解
Simple interest 单利a(t)=1+rt始终按最初本金计息
Compound interest 固定年实际利率 ia(t)=(1+i)t每期余额成为下一期本金
年名义利率 i(m)，一年复利 m 次a(t)=[1+i(m)/m]mt每次复利利率 = i(m)/m

单利固定 r，但第 k 年的实际利率为 r/[1+r(k-1)]，并不固定。单利中途关户、把全部余额重新存入新账户，会重新设定本金。例如 3% 单利存 2 年后重新存 3 年：P(1.06)(1.09)，不是 P(1.15)。固定复利则没有这种重存差别。

天数约定：exact = 实际天数/365 或 366（跨年分段）；ordinary = 按讲义的 30/360 规则；banker’s rule = 实际天数/360。ordinary 中 31 日及 2 月最后一天先改为 30 日。

02 利率先统一单位，再代公式

Effective ≠ nominal：年利率不一定能直接除以 12

Effective interest rate（实际利率）是某一段时间里，钱实际增加的比例；nominal interest rate（名义利率）是连同复利频率一起给出的报价。年金和贷款公式里的 i，必须是每个付款周期的实际利率。设付款间隔为 T 年：

i[s,t] = a(t)/a(s) - 1

题目给的利率每个付款周期的实际利率 j
年实际利率 ij = (1+i)T - 1
年名义利率 i(m)，一年复利 m 次j = [1+i(m)/m]mT - 1
年利息力 δ，连续复利j = eδT - 1

例：6% 年名义利率、每月复利，但每季付款。季度利率是 (1+0.06/12)3-1 = 1.5075%。若给的是 6% 年实际利率，月实际利率是 (1.06)1/12-1，不能用 0.06/12。

Force of interest δ(t)：瞬间的相对增长速度

δ(t) = a′(t)/a(t) = d[ln a(t)]/dt

a(t) = exp[∫0t δ(u) du]； a(t)/a(s) = exp[∫st δ(u) du]

给 a(t) 就求导再除以自身；给 δ(t) 就积分再取指数。δ 为常数时，a(t)=eδt，年实际利率 i=eδ-1。例如 δ=0.06，对应 i≈6.1837%，两者不同。单利 a(t)=1+rt 的 δ(t)=r/(1+rt)，会随时间下降。

Discount rate d：同一段利息，除以期末金额

若 100 一期后变成 110，i=10/100=10%，d=10/110≈9.09%。i 的分母是期初；d 的分母是期末。令 v 为每期贴现因子：

v = 1/(1+i) = 1-d； d = i/(1+i)； i = d/(1-d)

Simple discount：PV=F(1-dt)，a(t)=1/(1-dt)，需 dt<1；它与单利 PV=F/(1+rt) 不同。年名义贴现率 d(m) 对应 a(t)=[1-d(m)/m]-mt。

Inflation：关心能买多少，而不只是钱有多少

1+ireal = (1+i)/(1+π)； ireal = (i-π)/(1+π)

i 和通胀率 π 必须覆盖同一段时间。多个时段的增长倍数相乘，不直接把利率相加。i-π 只是小利率下的近似。

03 年金就是一串钱，逐笔折现

先数付款次数 n，再看第一笔什么时候付

Annuity 是按指定时间间隔支付的一串现金流。“年金”不代表一年付一次；可以每月、每季或连续支付。Level 表示金额固定。Annuity-certain 的期限固定；contingent 的付款取决于事件（如生存），本阶段主要学前者。

每期支付 P，利率 i 固定且为每个付款周期的实际利率，v=1/(1+i)。本笔记把讲义带横线的 n 简写为下标 n；s 的双点期初符号写作 sdue。a(t) 是增长函数，an|i 是年金现值因子，别混用。

n 笔，每笔 1PV：时间 0FV：时间 n
Immediate 期末付
时间 1,2,…,n		an|i = (1-vn)/isn|i = [(1+i)n-1]/i
Due 期初付
时间 0,1,…,n-1		än|i = (1+i)an|isn|idue = (1+i)sn|i

每笔是 P，就把表中的因子乘 P。PV 是把每笔钱向时间 0 折现；FV 是把每笔钱向时间 n 滚存。due 的每笔钱比 immediate 提前一期，因此在同一估值时点，价值多乘一个 (1+i)。

an|i = v+v2+…+vn； sn|i = (1+i)nan|i

Due 的标准 FV 仍在时间 n：最后一笔在 n-1 付，再计一期利息。若题目问“最后一笔刚付完”的金额，则是在 n-1，要用 P sn|i。i=0 时，四个基本因子都等于 n。

用一个小例子把公式连起来

每月底存 100，存 3 个月，月实际利率 1%。第三个月底：FV=100[(1.01)2+1.01+1]=303.01，即 100s3|0.01。若改成月初存，第三个月底：303.01×1.01=306.0401。

延迟与永续：看清第一笔付款

第一笔在 m+1，之后共 n 笔：PV = P vman|i = P(am+n|i-am|i)

第一笔在第 4 期：m=3，因为普通 immediate 本来就到第 1 期才付款。Perpetuity 是无穷多期；i>0 时，期末永续 PV=P/i，期初永续 PV=P(1+i)/i。

04 付款或利率会变：拆开再加

万能公式：找不到标准年金，就逐笔估值

PV = Σk=1n Pk/a(tk)； FV(T) = a(T) · PV

金额变了、利率变了、付款间隔变了，这两条仍然成立。标准公式只是特定现金流的求和结果；不必给每种题型另背一套逻辑。

利率分段变化：后半段要先在分界点估值

期末每期付 P：前 m 期每期利率 i，后 n 期每期利率 j。后 n 笔在时间 m 的价值是 P an|j，还要再折现 m 期回到 0。

PV = P am|i + (1+i)-m P an|j

一般每期利率 ik 不同，则 a(k)=∏h=1k(1+ih)。不能对全段套单一利率，也不能把 i、j 简单取平均。

付款为等差数列：每次增加 Q

第 k 期付款 Pk=P+(k-1)Q。P 是第一笔，Q 是每次增加的金额；减少时 Q<0。讲义记作 (IP,Qa)n|i。

PV = P an|i + (Q/i)[an|i-n vn]

FV = P sn|i + (Q/i)[sn|i-n]

递增 1,2,…,n：P=Q=1，记 (Ia)；递减 n,n-1,…,1：P=n、Q=-1，记 (Da)。若整串付款提前一期成为 due，在相同估值时点多乘 (1+i)。

付款为等比数列：每次增加 r%

第 k 期付款 Pk=P(1+r)k-1。r 是付款增长率，i 是资金利率，两者不是同一件事。以下为期末付款，且 i≠r：

PV = P{1-[(1+r)/(1+i)]n}/(i-r)

FV = P[(1+i)n-(1+r)n]/(i-r)

i=r 时，每笔付款折现后都等于 P/(1+i)，所以 PV=nP/(1+i)。等比永续要 i>r（假设 i,r>-1），才有 PV=P/(i-r)。

Continuous annuity：付款变成连续流量

PV = ∫0T f(t)/a(t) dt； FV(T) = ∫0T f(t)·a(T)/a(t) dt

f(t) 是每年的付款速度，不是一笔付款。常数速度 c、常数年利息力 δ：PV=c(1-e-δT)/δ，FV=c(eδT-1)/δ。δ=0 时两者为 cT。连续年金分母是 δ=ln(1+i)，不是年实际利率 i。

05 贷款 = 用未来还款抵掉本金

先抓住三个量：本金 L、每次还款 Pk、余额 Bk

OLB（outstanding loan balance）是尚欠余额。本笔记用 Bk=OLBk，默认是第 k 笔还款刚付完的余额；B0=L，完全还清时 Bn=0。先计息，再扣本次还款。

Bk = Bk-1 · a(tk)/a(tk-1) - Pk

L = Σk=1n Pk/a(tk)

第二式是 equation of value（价值方程）：今天借到的钱，等于所有未来还款今天的价值。计算存钱、退休提款、贷款，其实都在平衡同一时点的流入与流出。

每次还款分成利息和本金

Ik = ikBk-1； PRk = Pk-Ik = Bk-1-Bk

Ik 是本期利息；PRk 是本次真正减少的本金；ik 是本期实际利率。偿还金额不等于偿还本金。等额还款通常前期利息较多，随着余额下降，本金占比上升。

固定每期利率 i、期末等额还款 X、共 n 笔

L = X an|i； X = L/an|i = Li/[1-(1+i)-n]

方法第 k 笔付完的余额从哪边看
Retrospective 回顾法Bk = L(1+i)k-X sk|i本金终值 - 已还款终值
Prospective 前瞻法Bk = X an-k|i剩余 n-k 笔的现值
付款前余额 Bkbefore=Bk-1(1+i)；付款后 Bk=Bkbefore-X。求第 k 笔的利息，乘的是 Bk-1，不是 Bk。前瞻法要采用适用的剩余付款及未来利率。

用一个小例子建立直觉

借 1000，月实际利率 1%，分 2 次月末还：X=1000/a2|0.01≈507.5124。第一期 I1=10，PR1≈497.5124，B1≈502.4876。第二期 I2≈5.0249，余下部分还本金。总利息=2X-1000≈15.0249。

固定 X，反过来求需要多少期

n* = ln[X/(X-Li)] / ln(1+i)； 要求 i>0 且 X>Li

X=Li 时只够付利息；X<Li 时余额增加。i=0 则 n*=L/X。n* 不一定是整数，末次付款要调整；见下一页。

06 特殊贷款，也从余额继续算

Drop 与 balloon：最后一期究竟怎么结清

若理论期数 n*=m+f，m 是整数、0<f<1；先用回顾法算“付完 m 笔正常还款后”的 Bm。按照本讲义的正常调整方案：

方案最终付款已付的普通 X
Drop：到 m+1 期才结清D = Bm(1+i)，通常 D<X先付 m 笔 X
Balloon：提前到 m 期结清F = X+Bm = Bm-1(1+i)先付 m-1 笔 X

例：n*=27.58。drop 是 27 笔 X + 第 28 期较小尾款；balloon 是 26 笔 X + 第 27 期较大尾款。若 n* 为整数，就按原额正常结清。若题目另定结清日期，直接在那天求付款前余额。

利率变化 / refinancing：旧余额成为新本金

旧贷款第 k 笔付完 → Bk； 新每期利率 j、剩余 N 期：Y = Bk/aN|j

先按旧条款算到变更日的余额，再按新条款计算剩余还款；两笔贷款合并，就把当天的两个余额相加。未来付款改了以后，不能继续用原来的付款数额做前瞻估值。

Repayment holiday：暂停付款，利息仍累积

第 k 笔刚付完后，连续跳过 h 个付款日；在第 k+h+1 期恢复，还剩 N 笔等额还款。若每期利率仍为 i：

暂停结束时余额 = Bk(1+i)h； Y = Bk(1+i)h/aN|i

Sinking fund：贷款只还利息，另一个账户存本金

贷款本金 L 在期限内保持不变，每期向贷款方付 Li；另外向利率 j 的基金存 D，最终用基金偿还 L。若 n 次期末存款恰好达到 L：

D = L/sn|j； 每期总支出 = Li + D

同一期数、无额外费用、基金恰好达到 L：j=i 时总支出与等额摊还相同；j>i 时 sinking fund 较低；j<i 时摊还较低。这是讲义模型的数学比较。

其他还款规律：写出 Pk，再用余额递推

等额本金（不是等额还款）：每期本金 L/n，Bk=L(1-k/n)，Pk=L/n+iBk-1。因此还款会逐期减少，总利息=iL(n+1)/2。

若 Pk=c·本期利息，则 Bk=[1-(c-1)i]Bk-1。等比或等差还款则用第 4 页求价值；求剩余余额时，第一笔应改成下一笔尚未付的金额，不能继续用最初第一笔 P。

08 最后一轮：易错点 + 自检

四个自检：能答出，核心概念就接上了

1. 年名义利率 12%，每月复利、每季付款。年金公式用什么利率？
2. 第一笔在第 5 期，后面共付 n 笔 P，PV 是什么？
3. 第 10 笔还款付完后，还剩 20 笔等额 X。余额和第 11 笔利息分别是什么？
4. 每月初存钱，存 12 笔。第 12 笔刚存完，与第 12 个月底的金额，用哪个因子？

答案：1. (1.01)3-1=3.0301%。2. P v4an|i。3. B10=X a20|i；I11=iB10。4. 最后一笔刚存完（第 11 月）：P s12|i；第 12 月底：P s12|idue。

遇到陌生题，先排除这六个错误

① 把年实际利率直接除以 12。
② 把 due 的最后付款时点 n-1 当成标准 FV 时点 n。
③ 第一笔在第 q 期，却把 immediate 折现 q 期；应折现 q-1 期。
④ 求本期利息，用付款后的余额；应使用上期付款后的余额。
⑤ 把账户增长全当作利息，忘记扣掉新存款、加回提款。
⑥ 题目问“至少需要几次”，把解出的 23.38 四舍五入；应向上取整为 24。

期间实际赚得的利息 = 期末余额 - 期初余额 - 存入总额 + 提款总额

这一式使用该期间实际现金额，不把存款的未来价值当作“存入总额”；期初、期末是否已包含边界时点的存取，要保持一致。有中途存取时，不能直接用账户期末/期初余额-1 当作基金实际利率。

扩展公式定位：第 4 页不熟就回看这里

每次加金额 Q → 等差；每次乘 (1+r) → 等比；支付速度 f(t) → 积分；利率变动 → 分段；基金达到目标 → 写 FV≥目标；退休提款 → 在退休日令已积累金额=提款现值。
